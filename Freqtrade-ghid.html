Ghid de repo · freqtrade/freqtrade

Un bot care chiar plasează ordine pe exchange

Freqtrade e un bot open-source pentru trading crypto. Tu scrii strategia ca reguli în Python (indicatori, semnale de intrare și de ieșire). Botul o testează pe date istorice, o rulează pe bani virtuali și, când ești gata, o execută pe contul tău de exchange, 24 de ore din 24.

Aici sunt bani reali în joc. Spre deosebire de TradingAgents, Freqtrade execută ordine. Autorii spun clar că e software educațional și că nu trebuie să riști bani pe care nu-ți permiți să-i pierzi. Strategia de exemplu inclusă e doar o demonstrație, nu o strategie profitabilă.

Analist

Agenți LLM citesc știri, fundamentale și sentiment și scriu o opinie argumentată. Fără broker, fără ordine, cam o decizie pe zi. Costul vine din tokenii consumați.

Freqtrade

Executant

Reguli deterministe pe lumânări (5m, 1h, 1d…). Se conectează la exchange prin API, plasează ordine, administrează stop-loss-ul și ține evidența profitului. Nu folosește LLM-uri. Costul vine din comisioane și din pierderile strategiei.

    Anatomia unei strategii

    class RsiSimplu(IStrategy):
    timeframe = "1h"                 # ①
    minimal_roi = {"0": 0.04, "240": 0.02}  # ②
    stoploss = -0.05                  # ③
    trailing_stop = True

    def populate_indicators(self, df, metadata):  # ④
        df["rsi"] = ta.RSI(df, timeperiod=14)
        df["ema200"] = ta.EMA(df, timeperiod=200)
        return df

    def populate_entry_trend(self, df, metadata):  # ⑤
        df.loc[(df["rsi"] < 30) & (df["close"] > df["ema200"]),
               "enter_long"] = 1
        return df

    def populate_exit_trend(self, df, metadata):   # ⑥
        df.loc[df["rsi"] > 70, "exit_long"] = 1
        return df
    ①Mărimea lumânării. Pe 5m faci multe tranzacții și plătești multe comisioane. Pe 1h sau 4h zgomotul e mai mic.
    ②Ieșire pe profit în funcție de timp: 4% oricând, 2% după 240 de minute.
    ③Stop-loss la -5% față de intrare. Cu trailing_stop, urcă odată cu prețul.
    ④Calculezi indicatorii pe tot tabelul de lumânări (pandas + TA-Lib).
    ⑤Marchezi rândurile unde vrei să intri. Aici: RSI supravândut, dar doar în trend ascendent.
    ⑥Marchezi rândurile unde vrei să ieși. Botul se ocupă de ordine, de comisioane și de evidență.

    Exemplul e ilustrativ, nu o strategie recomandată. Șablonul oficial complet e freqtrade/templates/sample_strategy.py.

    Implementare

    Pornire, de pe Windows sau pe un server

    Cu Docker Desktop nu trebuie să instalezi TA-Lib manual, care pe Windows e partea cea mai dificilă. După instalarea Docker, repornește calculatorul, altfel apar probleme de rețea greu de explicat.

    1. Folder de lucru și imaginea oficială 
      mkdir ft_userdata && cd ft_userdata
curl https://raw.githubusercontent.com/freqtrade/freqtrade/stable/docker-compose.yml -o docker-compose.yml
docker compose pull
docker compose run --rm freqtrade create-userdir --userdir user_data
docker compose run --rm freqtrade new-config --config user_data/config.json

      new-config îți pune câteva întrebări. Alege dry-run: yes și activează FreqUI.

    2. Verifică setările de bani în config.json 
      {
  "dry_run": true,
  "dry_run_wallet": 1000,
  "stake_currency": "USDT",
  "stake_amount": 30,
  "max_open_trades": 3,
  "trading_mode": "spot"
}

      Astea sunt valorile din exemplul oficial pentru Binance. Cu spot nu folosești levier. Rămâi pe spot până înțelegi bine botul.

    3. Descarcă date și rulează un backtest 
      docker compose run --rm freqtrade download-data --pairs BTC/USDT ETH/USDT --exchange binance -t 1h --timerange 20250101-
docker compose run --rm freqtrade backtesting --strategy SampleStrategy -i 1h --timerange 20250101-20260901
docker compose run --rm freqtrade lookahead-analysis --strategy SampleStrategy -i 1h --timerange 20260101-20260901
    4. Pornește botul în dry-run și deschide interfața 
      docker compose up -d
# apoi în browser: http://localhost:8080
docker compose logs -f

    Un bot de trading trebuie să ruleze continuu, iar laptopul tău se închide. Cerințele recomandate sunt modeste: 2 GB RAM, 2 vCPU, 1 GB disc. Orice VPS mic Linux e suficient.

    1. Ceasul sincronizat (NTP)

      Exchange-urile resping cererile cu ora greșită. Pe Ubuntu, timedatectl trebuie să arate System clock synchronized: yes.

    2. Nu expune FreqUI pe internet

      FreqUI nu are HTTPS din fabrică. Accesează-l printr-un tunel SSH, iar pe server lasă portul legat doar la localhost:

      ssh -L 8080:localhost:8080 user@vps-ul-tau
    3. Cheia API de exchange, cu permisiuni minime

      Doar citire și trading. Niciodată retrageri (withdraw). Restricționează cheia la IP-ul VPS-ului, dacă exchange-ul permite.

    4. Notificări pe telefon

      Telegram e varianta oficială: /status, /profit, /daily, iar /forceexit all e frâna de urgență. Prin webhook-uri generice poți trimite evenimentele și într-un canal Teams.

    5. Actualizări 
      docker compose pull && docker compose up -d

      Citește changelog-ul înainte. Branch-ul stable e cel sigur, develop poate avea schimbări care strică ceva.

    Lucrăm cu Freqtrade (Docker, folderul curent e ft_userdata). Regulă fermă: rămânem pe "dry_run": true. Nu modifica asta și nu adăuga chei API reale.

1. Citește user_data/config.json și spune-mi pe scurt: exchange, trading_mode, stake, max_open_trades, pairlist.
2. Descarcă date 1h pentru BTC/USDT, ETH/USDT, SOL/USDT de la 2025-01-01.
3. Scrie în user_data/strategies/ o strategie simplă de trend (EMA 50/200 + RSI ca filtru), cu stoploss și minimal_roi explicite și comentarii în română.
4. Rulează backtesting pe 2025-01-01 – 2026-06-30 și raportează: număr de tranzacții, profit total, max drawdown, win rate, comparat cu buy&hold pe aceeași perioadă.
5. Rulează lookahead-analysis și recursive-analysis pe strategie. Dacă apare bias, repară-l înainte de orice altceva.
6. Testează separat pe 2026-07-01 – 2026-09-30 (date nevăzute la scriere). Dacă rezultatele diferă mult de pasul 4, spune-mi explicit că e semn de overfitting.
7. Nu rula hyperopt fără să-mi propui întâi spațiul de parametri și funcția de loss.

    TradingAgents ca filtru pentru Freqtrade

    Merge legat de raportul anterior: analiza LLM, lentă și de context, decide dacă ai voie să intri pe o monedă, iar regulile rapide din Freqtrade decid când.

    ZilnicTradingAgentsrulează pe BTC-USD, ETH-USD și scrie rating-ul într-un fișier JSON
    →
    Fișier comunratings.json{"BTC/USDT": "Overweight", "ETH/USDT": "Hold"}
    →
    La fiecare lumânareFreqtradeîn confirm_trade_entry() refuză intrările long pe monedele fără Buy/Overweight

    Limitarea e serioasă: filtrul nu poate fi testat în backtest-ul Freqtrade decât dacă ai rating-uri istorice. Le poți genera cu tradingagents backtest, care respectă datele cunoscute la fiecare dată, dar costul în tokeni crește cu fiecare zi din istoric. Aș testa ideea în dry-run, nu în backtest.
